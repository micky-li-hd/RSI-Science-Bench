§ 04  PROTOCOL

What counts

01

Frozen task

Reference code, judge, fixtures and instructions are content-checked before and after the agent.

02

Independent verify

The final candidate is run by a network-disabled verifier. Exact N0 equivalence and the task’s noise-adjusted benefit bar must both pass.

03

Transparent status

Provider cooldown and user cancellation remain unscored. A completed agent error, exactness failure or benefit-bar failure is shown separately and contributes zero to a completed model row; no speedup is fabricated.

Science Score / 50: for each task, a strict PASS with speedup S earns ln(S) / ln(best accepted S on that task); a completed rejected trial earns 0. We sum the ten task values and multiply by 5. Only complete model rows receive a score. Five ChemBERTa clean reruns are the scored trials because their first-attempt template contained prior optimization notes; those first attempts remain in the audit history. The other ten second attempts are separately labeled sensitivity checks, never best-of-two replacements. Gemini 4 Hydrogen uses Antigravity CLI on the same ten frozen science tasks; its row is unscored until complete. Infrastructure-invalid attempts are retained and replaced only by clean same-setting reruns. This uses the original benchmark's per-task logarithmic normalization, but not its ECI overall fit; these scores cannot be compared directly with the RSI-Infra leaderboard. The static snapshot updates only when audited and republished.
