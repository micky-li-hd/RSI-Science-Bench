§ 04  PROTOCOL

What counts

01

Frozen task

Reference code, judge, fixtures and instructions are content-checked before and after the agent.

02

Independent verify

The final candidate is run by a network-disabled verifier. Exact N0 equivalence and the task’s noise-adjusted benefit bar must both pass.

03

Transparent status

Provider cooldown, agent exit failures and user cancellation are separate from performance rejection. A failed or missing run never becomes a zero-speedup score.

Ranking here means strict PASS count, with geometric mean of accepted speedups only as a tiebreaker. It is not the original RSI-Infra ECI score. The static snapshot updates only when the export script is rerun and the site is republished.
